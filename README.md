# AnthracoForm

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20487673.svg)](https://doi.org/10.5281/zenodo.20487673)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

**Offline, single-file tools for anthracological determination and analysis.**

No installation, no server: each version is one HTML file that runs in any web browser
(Chrome or Edge recommended: they save directly to the CSV file) and stores data as R-ready CSV.

Meant for students and professionals alike: a switchable Help mode explains every field, IAWA features
are recorded as present, absent, required present or required absent (0–3, as the p/a/r/e
codes of InsideWood), saturation curves are drawn while you record, and PDF reports collect a record,
a taxon or a provisional type with all their photographs.

## Regional versions

| Version | Folder | Reference taxa | Status |
|---|---|---|---|
| Saharo-Sindian (Sindh) | [`Saharo-Sindian/`](Saharo-Sindian) | Indus plain and Thar, angiosperms, 25 taxa | v1.4 |
| Eastern Mediterranean (Lebanon) | [`Eastern-Mediterranean/`](Eastern-Mediterranean) | gymnosperms + angiosperms, 93 taxa | v0.6 (pre-release) |

Module names follow floristic regions (Loidi & Vynokurov 2024, *Mediterranean Botany*
45(2): e92333); the place in brackets is where the reference collection was made.
Until v1.2 the modules were called Sindh and Lebanon.

Each folder contains the HTML file, its own README, CHANGELOG and LICENSE.
Documentation (data dictionary, user guide and a short version of our laboratory protocol) is in [`docs/`](docs).

## How to cite

Cite the specific version you used; see the README in each folder.
The Zenodo concept DOI above always resolves to the latest archived release.
