# AnthracoForm — documentation (CSV schema v1.4)

Supplementary material for the AnthracoForm article (in preparation). The same files
describe the software archived on Zenodo: https://doi.org/10.5281/zenodo.20487673

| File | Content |
|---|---|
| `S1_AnthracoForm_data_dictionary_v1.4.xlsx` | Data dictionary: the 220 columns of the CSV file, controlled values, the IAWA hardwood (A) and softwood (G) feature lists used in the form, and an empty template sheet for converting existing datasets. |
| `S2_AnthracoForm_user_guide_v1.4.pdf` | User guide, step by step, with screenshots. |
| `S3_AnthracoForm_protocol.pdf` | Short version of the sampling and analysis protocol of our laboratory, on which AnthracoForm was built, and how each step is recorded in the form. It describes how we work; it does not prescribe how others should sample. |

The schema is the same in every regional module (Saharo-Sindian (Sindh), Eastern Mediterranean (Lebanon)).

**IAWA coding.** Each IAWA column holds: empty = not assessed, 0 = absent, 1 = present,
2 = required present (present and diagnostic), 3 = required absent (absent and diagnostic). The four values follow the
p/a/r/e codes of the InsideWood searches (1 = p, 0 = a, 2 = r, 3 = e).
