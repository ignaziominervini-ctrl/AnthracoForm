# AnthracoForm — documentation (CSV schema v1.3)

Supplementary material for the AnthracoForm article (in preparation). The same files
describe the software archived on Zenodo: https://doi.org/10.5281/zenodo.20487673

| File | Content |
|---|---|
| `S1_AnthracoForm_data_dictionary_v1.3.xlsx` | Data dictionary: the 220 columns of the CSV file, controlled values, the IAWA hardwood (A) and softwood (G) feature lists used in the form, and an empty template sheet for converting existing datasets. |
| `S2_AnthracoForm_user_guide_v1.3.pdf` | User guide, step by step, with screenshots. |

The schema is the same in every regional module (Saharo-Sindian (Sindh), Eastern Mediterranean (Lebanon)).
